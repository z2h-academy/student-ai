# AI Engineering Roadmap

Este repo es el punto de partida del módulo **AI Engineering** de Z2H Academy.

## Cómo empezar

1. **Forkea** este repositorio en tu cuenta de GitHub
2. **Crea un Codespace** desde el fork (`Code > Codespaces > Create codespace on main`)
3. Espera a que el entorno esté listo (90-120 segundos)
4. Abre la terminal y sigue las instrucciones del nivel correspondiente en el portal

## Stack

- Python 3.12
- PyTorch, Transformers, Sentence-Transformers
- Jupyter Notebooks
- Ollama (LLMs locales)
- PostgreSQL, MinIO, ChromaDB

## Contenido

Cada nivel del módulo se encuentra en el portal de Z2H Academy.
Este repo es solo el entorno de trabajo. No incluye la documentación pedagógica.

## Servicios

Los servicios (PostgreSQL, MinIO, Ollama, etc.) se levantan con Docker Compose
cuando sean necesarios. Sigue las instrucciones de cada nivel.
